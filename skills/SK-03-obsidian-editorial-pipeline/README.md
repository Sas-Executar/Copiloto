# Obsidian Editorial Pipeline V2.3

Interface operacional em português para percorrer o ciclo editorial pela **SOP-KP-001**
(processo definitivo, 8 blocos, gates reais) sem procurar arquivos manualmente e sem
preencher nada antes da hora. Abra `00 - COMEÇAR AQUI.md`.

Principais mudanças em relação à V2.2: a trilha não começa mais em "tema validado" —
ela respeita os gates reais (transformação → problema → público/contexto → perguntas
→ tese → inventário → MECE → escopo → sequência → outline → argumentos → evidências
→ claims → storyboard → brief visual → Content-Spec → artigo → visual → infográfico
→ vídeo → derivados → QA → operação); `problem_id` e demais artefatos nascem dentro
da trilha, não no formulário inicial; e o progresso é a razão real de etapas
concluídas, nunca degraus artificiais — "Pronto para gerar ZIP" e "100% Empacotado"
substituem o antigo 99%/100% quantizado. Ver `references/sop-kp-001.md`.
