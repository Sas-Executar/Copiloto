# Edge Cases

## No progress data
Set percentages to null and render `—`, never `0%`.

## No temporal structure
Use `Não identificado no documento` for triptych titles and null percentages.

## Conflicting status
Preserve the conflict in `quality.conflicts` and use neutral visible wording.

## Multiple projects
Create separate reports unless a portfolio report is explicitly requested.

## Strategy document without tasks
Map supported context/problem/process/delivery; keep now/steps missing rather than inventing execution.

## Task list without narrative
Derive only mechanically safe values such as completion counts, explicit due dates, and explicit next incomplete action.

## Very long source
Use staged extraction: source inventory → section synthesis with provenance → canonical mapping.

## Recommendations requested
Keep source-derived report separate from prescriptive recommendations unless a prescriptive mode is explicitly requested.
