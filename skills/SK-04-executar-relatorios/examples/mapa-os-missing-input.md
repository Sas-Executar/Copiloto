# Informação ausente — sem evidência de conclusão

## Entrada

O status declara “feito”, mas o contrato exige prova de teste e nenhuma evidência foi fornecida.

## Esperado

Preservar o estado anterior suportado, criar lacuna de evidência e pedir apenas o registro do teste ou autorização para manter a etapa pendente.

## Proibido

Interpretar a palavra “feito” como verificação concluída.
