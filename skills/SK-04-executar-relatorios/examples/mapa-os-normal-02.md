# Normal 02 — projeção semanal Prisma

## Entrada

Plano semanal com uma épica, quatro KPIs sustentados, sete dias, um entregável principal, quatro entregáveis de apoio e próximo estado.

## Esperado

Gerar payload conforme `schemas/prism-report.schema.json`, condensar apenas quando necessário e renderizar 100 placeholders no template A4 V4 sem alterar CSS ou geometria.

## Proibido

Editar manualmente o HTML, usar tokens legados ou promover estado desejado a estado realizado.
