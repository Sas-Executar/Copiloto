Checklist de Product Management — Ciclo de Desenvolvimento de Produto

Fase

Descrição

Tópicos / Atividades

Entregáveis obrigatórios + questões de controle

01. Identificação do problema / oportunidade

Determinar qual problema merece ser resolvido e por quê.

Dor do cliente; mercado; negócio; contexto; stakeholders; evidências iniciais.

☐ Problem Statement ☐ oportunidade documentada ☐ stakeholders. Questões: Para quem? Qual problema? Qual impacto? Que evidência existe?

02. Discovery / Pesquisa

Investigar problema, usuário e contexto antes de definir solução.

Entrevistas; dados; benchmark; jornada; personas/JTBD; hipóteses.

☐ Plano de pesquisa ☐ entrevistas/dados ☐ jornada ☐ hipóteses. Questões: Problema é real? Frequente? Relevante? Como é resolvido hoje?

03. Estratégia de Produto

Definir direção, valor e resultados esperados.

Visão; posicionamento; público; proposta de valor; objetivos; métricas.

☐ Product Vision ☐ Value Proposition ☐ objetivos/OKRs ☐ KPIs. Questões: Por que este produto? Para quem? Qual diferencial? Como sucesso será medido?

04. Priorização

Escolher problemas e oportunidades de maior valor.

RICE; ICE; MoSCoW; Value × Effort; impacto; risco; dependências.

☐ Backlog priorizado ☐ critérios registrados ☐ decisão de escopo. Questões: Maior impacto? Custo? Risco? Urgência?

05. Definição da solução

Transformar problema validado em solução executável.

Requisitos; UX; fluxos; arquitetura funcional; MVP; protótipos.

☐ PRD ☐ fluxos ☐ protótipo ☐ escopo MVP ☐ critérios de aceite. Questões: Qual mínimo necessário? O que fica fora?

06. Validação

Reduzir risco antes do desenvolvimento completo.

Testes de usabilidade; protótipos; experimentos; entrevistas; viabilidade.

☐ Plano de teste ☐ resultados ☐ evidências ☐ decisão Go/No-Go. Questões: Usuário entende? Usa? Valor foi comprovado?

07. Delivery / Desenvolvimento

Construir e garantir qualidade da solução.

Engenharia; design; QA; refinamento; sprints; segurança; implementação.

☐ Backlog técnico ☐ release candidate ☐ QA aprovado ☐ documentação. Questões: Critérios atendidos? Riscos resolvidos? Pronto para produção?

08. Lançamento / Go-to-Market

Disponibilizar produto e preparar operação comercial.

Release; comunicação; marketing; vendas; onboarding; suporte; treinamento.

☐ GTM Plan ☐ release notes ☐ documentação ☐ suporte preparado. Questões: Quem lança? Para quem? Quando? Como comunicar?

09. Medição

Verificar comportamento e resultados reais.

Adoção; ativação; retenção; receita; satisfação; qualidade; funil.

☐ Dashboard ☐ KPIs ☐ baseline ☐ relatório pós-lançamento. Questões: Objetivos foram atingidos? Onde há abandono?

10. Aprendizado e otimização

Converter dados e feedback em melhorias.

Feedback; analytics; bugs; experimentos; análise de causa; iteração.

☐ Insights ☐ backlog de melhorias ☐ decisões documentadas. Questões: O que funcionou? O que falhou? O que mudar?

11. Growth / Escala

Ampliar crescimento sustentável do produto.

Aquisição; ativação; retenção; monetização; referral; expansão.

☐ Growth backlog ☐ experimentos ☐ métricas AARRR. Questões: Qual alavanca limita crescimento? É escalável?

12. Maturidade / Manutenção

Sustentar qualidade, eficiência e rentabilidade.

Performance; estabilidade; dívida técnica; custos; segurança; melhorias incrementais.

☐ SLA/SLO ☐ roadmap técnico ☐ plano de manutenção. Questões: Produto permanece competitivo, seguro e rentável?

13. Evolução / Pivot / Descontinuação

Decidir o futuro do produto com base em evidências.

Renovação; reposicionamento; pivot; substituição; sunset; migração.

☐ Lifecycle Review ☐ decisão executiva ☐ plano de transição. Questões: Investir, manter, pivotar ou encerrar? Por quê?

Fluxo: Discover → Define → Design → Validate → Build → Launch → Measure → Learn → Iterate.
