Objetivo

Formulário de preenchimento manual para organizar tópicos, decisões, evidências e próximas ações em cada domínio do HUB-EXECUTAR.

Como usar

• Preencha somente o que existe. Se não houver dado suficiente, marque LACUNA; não complete por plausibilidade.

• Cada área contém os mesmos quatro blocos: Resumo Executivo, JTBD, 5W2H e PDCPA.

• JTBD = Jobs to Be Done (referido no pedido como “JBTD”).

• PDCPA é apresentado como cinco campos operacionais P1 / D / C / P2 / A, sem assumir uma nomenclatura adicional além do que está explicitado no formulário.

• Nenhuma caixa abaixo vem pré-marcada.

• Decisões estruturais ou mudanças relevantes devem ser registradas também em D22.
